# File & Directory Descriptions

This document explains the purpose of the primary directories and files in this repository.

## Root Directory

*   `/AGENTS.md`: The central hub for AI agent instructions and project rules.
*   `/AGENTS_SETUP.md`: Brief overview of the setup process.
*   `/setup_env.sh`: Script to automatically set up the Android development environment.
*   `/docs/`: Contains extended documentation for various aspects of the project.

## The `/docs/` Directory

*   `AGENT_GUIDE.md`: General principles and guidelines for AI agents.
*   `TODO.md`: Tracking of upcoming tasks and features.
*   `UI_UX.md`: Design system, accessibility, and interaction guidelines.
*   `auth.md`: Authentication flows and security rules.
*   `conduct.md`: Coding standards and review process.
*   `data_layer.md`: Architecture of repositories, network, and database interaction.
*   `fauxpas.md`: Anti-patterns and mistakes to avoid.
*   `file_descriptions.md`: (This file) Overview of the project structure.
*   `misc.md`: Miscellaneous guidelines not fitting elsewhere.
*   `performance.md`: Performance expectations and profiling guidelines.
*   `screens.md`: Definitions and flow of application screens.
*   `task_flow.md`: Guidelines on how features should be implemented step-by-step.
*   `testing.md`: Testing standards, tools, and methodologies.
*   `workflow.md`: Branching strategy, PR processes, and CI/CD.
